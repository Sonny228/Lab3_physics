C++17, SFML 3.0.2 (скачивается автоматически через CMake FetchContent), Visual Studio 2022.
Вариант задачи: **круги** (стенки - прямоугольники AABB без вращения).

## Что нужно
* Visual Studio 2022 с компонентами **«Разработка классических приложений на C++»** и **«Инструменты CMake для C++»**
* Интернет при первой конфигурации (CMake скачает SFML с GitHub)

## Сборка в Visual Studio 2022
1. `Файл → Открыть → Папку…` и выбрать папку проекта (где лежит `CMakeLists.txt`). **Именно папку**, а не отдельный файл.
2. Подождать, пока в окне «Вывод» CMake допишет `Generation finished` (в первый раз 2-5 минут: качается и собирается SFML).
3. Вверху выбрать конфигурацию **x64 Release** (все замеры времени делать только в Release!).
4. В выпадающем списке запуска выбрать `pz3.exe` и нажать `Ctrl+F5` (или `Сборка → Собрать все`, затем запуск).

Из командной строки (x64 Native Tools Command Prompt for VS 2022):
```
cmake --preset x64-release
cmake --build --preset x64-release
out\build\x64-release\pz3.exe
```

## Запуск
* `pz3.exe` - окно со сценами (HUD сверху, клавиша `H` - подсказка по клавишам).
* `pz3_experiments.exe` или клавиша `T` в окне (или `pz3.exe --experiments`) - все эксперименты без отрисовки.
  Результат печатается в консоль и сохраняется в `experiments.txt` **рядом с exe** (`out\build\x64-release\`).
  
## Цветовая индикация
* Сцена Multi-rate: Серые круги — неподвижные (static); Синие — обычные (slow, 60 Гц); Оранжевые — быстрые (fast, 240 Гц).
* Сцена Tunnel: Зеленые шары — отскочили от стенки; Розовые — снаряд пролетел сквозь стенку.
* Сцены Room / Stack: Синие шары.

## Клавиши
| Клавиша | Действие |
|---|---|
| `1` `2` `3` `S` | сцены: Room, Tunnel, Multi-rate, Stack |
| `D` `C` `M` | режим: Discrete, CCD, Multi-rate |
| `4` `5` `6` | частота физики 60 / 120 / 240 Гц |
| `P` / `N` | пауза / один шаг на паузе |
| `I` | интерполяция вкл/выкл |
| `R` | перезапуск сцены |
| `↑` `↓` | коэффициент восстановления e ± 0.1 |
| `←` `→` | скорость снаряда ∓ 500 px/с (перезапуск) |
| `T` | эксперименты |
| `F12` | скриншот `screenshot_N.png` (в рабочую папку) |
| `H` / `Esc` | подсказка / выход |

## Структура
| Файл | Назначение |
|---|---|
| `src/Config.h` | **все числовые параметры** (единственный файл, который меняется под свой вариант) |
| `src/Vec2.h` | 2D-вектор |
| `src/Physics.h/.cpp` | тела, стенки, три режима шага: дискретный, CCD, multi-rate |
| `src/Scenes.h/.cpp` | сцены Room / Tunnel / Multi-rate / Stack |
| `src/Experiments.h/.cpp` | эксперименты: туннелирование, детерминизм, время шага, стек |
| `src/main.cpp` | окно SFML, цикл с аккумулятором, интерполяция, HUD, клавиши |
| `src/ExperimentsMain.cpp` | консольный запуск экспериментов без SFML |
